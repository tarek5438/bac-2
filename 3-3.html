🧭 مدخل الدرس: كيف تتكامل تقنيات الواجهة الأمامية لبناء صفحة ويب؟

عند فتح أي صفحة ويب، فإنك ترى ثلاث تقنيات تعمل معاً: تتولى لغة HTML بناء الهيكل — أي العناوين والفقرات والروابط — تماماً مثل هيكل المبنى. وتضيف لغة CSS المظهر — كالألوان والتخطيط والخطوط — بما يشبه التصميم الداخلي للمبنى. أما لغة JavaScript فتضيف السلوك التفاعلي — مثل مربعات البحث المستجيبة، والأزرار التي تقوم بعمليات العد، والشاشات التي تُحدّث بياناتها. وتذهب تقنيات الواجهة الأمامية (Frontend) الحديثة إلى أبعد من ذلك؛ إذ تجعل الصفحات ذات دلالة واضحة، وقابلة للتكيف مع مختلف أحجام الشاشات، وأسرع في عملية التطوير.

🏗️تشبيه الكتاب المدرسي (ص 63): بناء وتجهيز مبنى متكامل!

يُشبّه الكتاب المدرسي بناء صفحة الويب بتشييد مبنى:
1. لغة HTML (هيكل مبنى): الأعمدة والجدران والغرف التي تحدد بنية الصفحة وعناصرها كالعناوين والفقرات والصور والروابط.
2. لغة CSS (الديكور الداخلي والخارجي لمبنى): الطلاء والألوان والإضاءة وتنسيق الأثاث والخطوط والتخطيط.
3. لغة JavaScript (أنظمة الكهرباء والسباكة في مبنى): الأنظمة الحيوية التي تجعل المبنى يتفاعل معك عند الضغط على مفتاح إضاءة أو زر مصعد (تفعيل الاستجابات وتحديث جزء فقط من الشاشة).

❓ السؤال الرئيسي للدرس (ص 63): كيف تعمل HTML وCSS وJavaScript معاً لبناء صفحة ويب، وما الذي يجعل الواجهة الأمامية الحديثة ذات معنى وقابلة للتكيف وفعّالة في البناء؟

🧱 1. أدوار HTML و CSS و JavaScript في بناء صفحة الويب

تؤدي التقنيات الثلاث أدواراً مختلفة في كثير من صفحات الويب؛ وليس من الضروري أن تستخدم الصفحة الثلاث كلها معاً، بل يمكن أن تستخدم الصفحة HTML وحده، أو HTML مع CSS وJavaScript بحسب الوظائف التي تحتاج إليها (ص 63 - 64).

التقنية الدور الأساسي في صفحة الويب (كتاب ص 63) التشبيه في الكتاب
HTML
(البنية / Structure)		 يحدد بنية (هيكل) صفحة الويب. يصف عناصر مثل العناوين والفقرات والصور والروابط. 🏗️ هيكل مبنى
CSS
(المظهر / Appearance)		 يحدد مظهر صفحة الويب (الألوان، التخطيط، الحجم، الخطوط، إلخ). 🎨 الديكور الداخلي والخارجي لمبنى
JavaScript
(السلوك / Behavior)		 يضيف السلوك والتفاعلية إلى صفحة الويب. يُفعّل الاستجابات عند الضغط على الأزرار وتحديثات جزء فقط من الشاشة. ⚡ أنظمة الكهرباء والسباكة في مبنى

🏷️ 2. HTML الدلالية (Semantic HTML) و 3. التصميم المتجاوب (Responsive Design)

🏷️ أولاً: HTML الدلالية (Semantic HTML)

التعريف (ص 64): استخدام عناصر توضح وظيفة أجزاء الصفحة، بدلاً من الصناديق العادية غير المعبرة:

  • <header>: في أعلى الصفحة (الترويسة).
  • <nav>: للتنقل (قائمة الروابط).
  • <main>: للمحتوى الرئيس للصفحة.
  • <footer>: في أسفل الصفحة (التذييل).

فوائد استخدام HTML الدلالية:
① إمكانية الوصول (Accessibility): يساعد قارئ الشاشة (Screen Reader) على فهم بنية الصفحة والتنقل فيها، مع الحاجة إلى ممارسات وصول أخرى أيضاً.
② فهم محركات البحث للمحتوى (SEO): قد يساعد محركات البحث على فهم بنية المحتوى بصورة أفضل، لكنه لا يضمن ترتيباً أعلى.

📱 ثانياً: التصميم المتجاوب (Responsive Design)

التعريف (ص 64): مفهوم تصميمي يُضبط فيه التخطيط تلقائياً وفقاً لأحجام الشاشات المختلفة مثل أجهزة الكمبيوتر والهواتف الذكية والأجهزة اللوحية.

  • أهميته: يساعد الصفحة على التكيف مع أحجام الشاشات المختلفة وتحسين سهولة استخدامها.
  • نهج الأولوية للجوال (Mobile-First): يستخدم كثير من الناس الويب عبر الهواتف، لذلك يراعي المطورون الشاشات الصغيرة منذ بداية التصميم.
  • تنبيه هام (تدرّب 2 ص 66): HTML الدلالية والتصميم المتجاوب لا يجعلان سرعة عرض الصفحة أسرع بالضرورة، بل يحسنان الفهم والتكيف وسهولة القراءة.

📲 محاكي HTML الدلالية والتصميم المتجاوب عبر أحجام الشاشات:

<header> ترويسة الموقع الإخباري عرض مكتب (100%)
<nav> قائمة التنقل: الرئيسية | أخبار التقنية | الفعاليات
<main> المحتوى الرئيس (يتكيف تلقائياً مع الشاشة):
📰 خبر 1: الذكاء الاصطناعي
🛡️ خبر 2: الأمن السيبراني
🌐 خبر 3: تطبيقات الويب
<footer> تذييل الصفحة - جميع الحقوق محفوظة
🖥️ وضع الكمبيوتر + HTML الدلالية (ص 64): العناصر الدلالية (<header>, <nav>, <main>, <footer>) توضح وظيفة كل جزء لقارئ الشاشة ومحركات البحث، بينما يعرض التصميم المتجاوب البطاقات في 3 أعمدة مريحة.

⚙️ 4. أطر العمل والمكتبات الشائعة لتطوير الويب (React، Vue، Next.js)

إطار العمل (Framework): بنية توفر مسبقاً وظائف ومكونات شائعة الاستخدام، وذلك لجعل عملية تطوير تطبيقات الويب أكثر كفاءة. وعند استخدام إطار عمل، لا يحتاج المطورون إلى كتابة كامل الكود البرمجي من الصفر، ويمكنهم التطوير بكفاءة أكبر (ص 65).

المكتبة / إطار العمل الخصائص والدور في الكتاب المدرسي (ص 65) الميزة الجوهرية
React مكتبة JavaScript لبناء واجهات المستخدم من مكونات قابلة لإعادة الاستخدام (Reusable Components) وتحديثها عند تغير البيانات. مكونات واجهة قابلة لإعادة الاستخدام.
Vue له بنية بسيطة ويتيح بناء تطبيقات الويب تدريجياً بدءاً من ميزات صغيرة. البساطة والتدرج من ميزات صغيرة.
Next.js إطار مبني على React لبناء تطبيقات ويب، ويوفر التوجيه (Routing) وطرقاً مختلفة لعرض الصفحات والعمل على الخادم والعميل. مبني على React + توجيه وعمل على الخادم والعميل.

🧭 محاكي مستشار اختيار المكتبة أو إطار العمل (كتاب ص 65):

⚛️ مكتبة React (ص 65): مكتبة JavaScript تركز على بناء واجهات المستخدم من مكونات (Components) قابلة لإعادة الاستخدام وتحديثها تلقائياً عند تغير البيانات دون إعادة كتابة الكود من الصفر.

📗 جميع أسئلة وأنشطة وتمارين الكتاب المدرسي محلولة بالتفصيل

💡 1. أنشطة «توقّف وفكّر» (ص 64، 65، 66) + «المثال المحلول» (ص 65)▼

توقّف وفكّر (ص 64): في صفحة تستخدمها كثيراً، ما هي الأجزاء التي تمثل البنية (HTML)، وما هي التي تمثل الشكل (CSS)، وما الذي يتفاعل معك (JavaScript)؟
⬅️ الإجابة:
• البنية (HTML): عناوين المقالات أو الفيديوهات، الفقرات النصية، الصور، وروابط القوائم.
• الشكل والمظهر (CSS): ألوان الخلفية والأزرار، نوع وحجم الخطوط، وتوزيع البطاقات في شبكة متناسقة.
• التفاعل والسلوك (JavaScript): مربع البحث الذي يقترح نتائج فورية أثناء الكتابة، زر «أعجبني» الذي يزيد العداد فوراً، وتحديث التعليقات دون إعادة تحميل الصفحة.

توقّف وفكّر (ص 65): لماذا يفهم قارئ الشاشة الصفحة بشكل أفضل عندما نستخدم <header> و<nav> و<main> بدلاً من صناديق عادية؟
⬅️ الإجابة: لأن هذه العناصر الدلالية (Semantic HTML) تحمل معنى يوضح وظيفة كل جزء في الصفحة (أعلى الصفحة، قائمة التنقل، المحتوى الرئيس)؛ فيستطيع برنامج قارئ الشاشة إخبار المستخدم الكفيف أو ضعيف البصر بمكان وجوده والقفز مباشرة إلى المحتوى الرئيس أو قائمة التنقل، بينما الصناديق العادية لا توضح وظيفة المحتوى بداخلها.

توقّف وفكّر (ص 66): أي من الفوائد تتعلق بمظهر الصفحة، وأيها تتعلق بمدى سهولة إيجادها وقراءتها من قبل الآخرين؟
⬅️ الإجابة:
• تتعلق بمظهر الصفحة وتكيفها البصري: التصميم المتجاوب وتنسيق CSS.
• تتعلق بسهولة إيجادها وقراءتها من قبل الآخرين (بمن فيهم ذوو الإعاقة البصرية ومحركات البحث): لغة HTML الدلالية التي تدعم إمكانية الوصول (Accessibility) وتحسين محركات البحث (SEO).

المثال المحلول (ص 65):
(1) ضع علامة ○ أو ×:
• أ: ○ (تحدد HTML بنية وهيكل صفحة الويب).
• ب: × (CSS تقنية تحدد مظهر صفحة الويب، أما إضافة السلوك فهي JavaScript).
• جـ: ○ (تعريف صحيح للتصميم المتجاوب الذي يُضبط فيه التخطيط تلقائياً وفقاً لأحجام الشاشات).
• د: ○ (وصف صحيح لفائدة أطر العمل في إلغاء الحاجة لكتابة كل الكود من الصفر).
(2) المطابقة:
• 1: يحدد بنية صفحة الويب ⬅️ (أ) HTML.
• 2: يحدد مظهر صفحة الويب ⬅️ (ب) CSS.
• 3: يضيف السلوك والتفاعلية إلى صفحة الويب ⬅️ (جـ) JavaScript.

📝 2. سؤال الامتحان [6 درجات] (ص 66) + «تدرّب 1 و 2» (ص 66)▼

سؤال على نمط الامتحان [6 درجات] (ص 66): اشرح كيف تساهم كل من HTML وCSS وJavaScript في صفحة مكتبة تعرض قائمة كتب، وتكون منسّقة، وتُصفّي النتائج أثناء كتابة المستخدم (راجع: البنية، المظهر، السلوك):
⬅️ الإجابة النموذجية:
1. HTML (البنية): تبني هيكل صفحة المكتبة وتحدد عناصرها الأساسية مثل عنوان المكتبة، وحقل إدخال البحث، وقائمة عناوين الكتب والفقرات والصور.
2. CSS (المظهر): تنسّق مظهر صفحة المكتبة، فتحدد ألوان الواجهة، والخطوط، وتخطيط بطاقات الكتب وأحجامها لتظهر بشكل منظم وجذاب.
3. JavaScript (السلوك): تضيف السلوك التفاعلي، فتستجيب فوراً أثناء كتابة المستخدم في مربع البحث وتقوم بتصفية قائمة الكتب وتحديث الجزء المعروض على الشاشة دون إعادة تحميل الصفحة كاملة.

حل تدرّب 1 (ص 66):
1) الاختصار المكوّن من أربعة أحرف لبنية صفحة الويب: HTML.
2) الاختصار المكوّن من ثلاثة أحرف لمظهر صفحة الويب: CSS.
3) مصطلح التقنية التي تضيف السلوك والتفاعلية: JavaScript.
4) مصطلح مفهوم التصميم الذي يُضبط فيه التخطيط تلقائياً وفقاً لأحجام الشاشات: التصميم المتجاوب (Responsive Design).

حل تدرّب 2 (ص 66):
(1) الخيار الذي لا يمثل فائدة مناسبة لاستخدام HTML الدلالية هو: (جـ) تصبح سرعة عرض صفحة الويب أسرع بالضرورة.
(2) الخيار الذي يصف إطار العمل بأنسب شكل هو: (ب) بنية تجعل تطوير تطبيقات الويب أكثر كفاءة.

⚙️ 3. حل «فكّر كمهندس: ابحث ثم قرر» (ص 66) + «طبّق ما تعلمته» (ص 67)▼

حل نشاط «فكّر كمهندس: ابحث ثم قرر» (صفحة النادي الطلابي ص 66):
1. لاحظ أولاً (توزيع الميزات الثلاث):
• قائمة الفعاليات ⬅️ HTML (لأنها تمثل بنية المحتوى والنصوص والعناوين).
• ألوان النادي وتخطيطه ⬅️ CSS (لأنها تحدد المظهر البصري والألوان وتنسيق الصفحة).
• عدّاد التسجيل الحي عند النقر على الزر ⬅️ JavaScript (لأنه يضيف السلوك التفاعلي ويُحدّث الرقم على الشاشة فوراً).
2. اجعلها تصل إلى الجميع:
• تغيير لجعل الصفحة أسهل قراءة على الهاتف (التصميم المتجاوب): ضبط التخطيط تلقائياً ليتحول إلى عمود واحد مع تكبير حجم الخط والأزرار لتناسب شاشات الجوال.
• اختيار في HTML الدلالية يساعد قارئ الشاشة: استخدام عناصر دلالية مثل <header> لترويسة النادي، و<nav> للتنقل، و<main> لقائمة الفعاليات.
3. القرار: نوصي بـ ☑️ استخدام HTML وCSS وJavaScript كلاً حسب دوره الصحيح وفصل الأدوار؛ لأن ذلك (1) يسهّل صيانة الصفحة وتعديل المظهر أو السلوك دون إفساد البنية، و(2) يجعل الكود منظماً وقابلاً لإعادة الاستخدام والتعاون بين أعضاء الفريق.

حل نشاط «طبّق ما تعلمته» - الموقع الإخباري (ص 67):
• اختيار في التصميم المتجاوب وفائدته: اعتماد تخطيط مرن يراعي نهج الأولوية للجوال (Mobile-First) بحيث يتكيف عرض الأخبار والصور تلقائياً مع شاشات الهواتف الذكية؛ وفائدته تحسين سهولة القراءة والاستخدام على الهاتف.
• اختيار في HTML الدلالي وفائدته: هيكلة الصفحة باستخدام العناصر الدلالية (<header>، <nav>، <main>، <footer>)؛ وفائدته مساعدة محركات البحث (SEO) وتقنيات قارئ الشاشة على فهم بنية صفحات الموقع بدقة.

🏆 4. إجابة السؤال الرئيسي + حل تمارين نهاية الدرس + «فكّر وتحدَّ نفسك» (ص 67)▼

إجابة السؤال الرئيسي (ص 67): تستخدم كثير من صفحات الويب HTML لبناء الهيكل، ويمكن أن تضيف CSS للمظهر وJavaScript للتفاعل بحسب الحاجة. ويستخدم HTML الدلالي عناصر توضح وظيفة أجزاء الصفحة، ما يساعد التقنيات المساعدة ومحركات البحث على فهم بنيتها. ويجعل التصميم المتجاوب الصفحة تتكيف مع أحجام الشاشات المختلفة. كما تساعد المكتبات والأطر على بناء الواجهة من مكوّنات قابلة لإعادة الاستخدام وتقليل بعض العمل المتكرر؛ فـ React مكتبة لبناء واجهات المستخدم، وNext.js إطار مبني عليها لبناء تطبيقات ويب.

حل تمارين نهاية الدرس (ص 67):
• سؤال 2 (إكمال الفقرة): (1) HTML | (2) CSS | (3) JavaScript | (4) التصميم المتجاوب.
• سؤال 3-(1) (تحديد التقنية: أ HTML، ب CSS، جـ JavaScript):
1 وصف بنية العناوين والفقرات ⬅️ أ (HTML)
2 تغيير لون النص وحجمه ⬅️ ب (CSS)
